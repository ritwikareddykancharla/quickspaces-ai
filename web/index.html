01 · Problem

Problem

A shared team workspace holds spreadsheets, BI dashboards, call transcripts, and design docs under different access levels. Indexing all of them in a flat vector store introduces three failure modes.

10 Queries · 5 Access Probes · 3 Workspaces

Permission Checks and Search Across Four File Formats

Suppose a shared workspace holds four files on Q3 cloud revenue: a finance spreadsheet with customer revenue alongside Social Security numbers and API keys, an executive BI dashboard, a 45-minute customer escalation call, and an engineering design doc. Answering "What drove the Q3 European revenue drop and when does the fix ship?" requires the account contraction numbers from the spreadsheet, the regional trend from the dashboard, and the November 18 ship date stated at [08:45] on the call.

Standard retrieval fetches global top matches first and checks permissions afterward. If confidential files take the top slots, lower-clearance users get empty answers or unmasked sensitive columns leak into the prompt. At the same time, long call transcripts produce dozens of chunks and crowd out compact tables. QuickSpaces checks caller permissions and masks sensitive columns before scoring any candidate, pools chunk scores per file, and audits workspace security controls.

01 · POST-SEARCH PERMISSION GAPS

Post-Search Filtering Leaks Data or Starves Results

Fetching global top-K chunks before checking permissions lets confidential transcripts occupy every top slot. Lower-clearance callers receive empty results even when public files exist, or unmasked columns (signatory_ssn, cfo_contact_phone, connector_api_key) enter prompt assembly.

5 contractor & regional access probes tested against restricted files
02 · VERBOSE TRANSCRIPT BIAS

Long Call Recordings Crowd Out Compact Tables

Splitting spreadsheets, dashboard cards, 45-minute call recordings, and design docs into uniform text chunks lets a 40-turn call fill the top slots while numeric rollups (sum, avg, cohort deltas) miss the cutoff. Flat chunk ranking reaches 80.0% top-3 recall.

80.0% top-3 recall with flat chunk ranking vs. 90.0% with per-file pooling
03 · CONFIGURATION DRIFT

Shared Folders Accumulate Unmasked PII and Guest Links

Teams upload spreadsheets and call recordings into shared workspaces without locking sensitive columns, revoking external contractor links, pinning European data to eu-central-1 KMS keys, or setting 90-day retention tags.

59.7 / 100 average starting security score across the 3 workspaces

Example: Answering an EMEA Revenue Question Across Two Access Levels

Request trace for POST /api/spaces/space-q3-cloud-arr/ask on the question: "How much did NordBank and AlpineRe EMEA ARR contract in Q3, and when does SCIM v2 ship?"

Step 1 · Permission Gate (0.18 ms) For an external contractor, can_access_asset() excludes 4 of the 5 workspace files before search runs, leaving only the public pricing guide (0 leaks). For a VP Admin, all 5 files remain eligible.
Step 2 · Hybrid Search (0.70 ms) HybridRetriever scores cleared chunks with Okapi BM25 and 3-gram cosine similarity, combines ranks via 1/(60 + r), and pools the highest chunk score per file so the spreadsheet (C1), BI dashboard (C2), call recording (C3), and RFC (C4) all rank in the top set.
Step 3 · Cited Answer & Verification Amazon Bedrock (us.amazon.nova-lite-v1:0) cites -$620K NordBank and -$460K AlpineRe [C1], 79.0% EMEA net retention [C2], and the Nov 18, 2026 GA date at [08:45] [C3][C4]. Every [Ck] citation is checked against retrieved spans (100.0% precision).
Step 4 · Chart & Security Audit When a question matches quantitative retention series, QuickSpaces renders a 5-bar SVG comparison chart (119.6% NA vs. 79.0% EMEA). The security auditor flags unmasked SSN or API key columns for one-click remediation (59.7 → 100).

03 · Implementation

Implementation

Format-specific parsers, pre-retrieval access gates, 40-page SHA-256 Merkle incremental indexing with multi-page table header propagation, O(1) bitmap tombstones, and SQLite WAL spec-driven AgentZ workflows in quickspaces/.

MULTI-PAGE TABLES & INCREMENTAL SYNC

Header Propagation Across Page Breaks & SHA-256 Merkle Delta Sync

Splitting a 40-page enterprise PDF into fixed blocks strips column names from continuation tables on pages 8, 9, 14, 23, and 28, leaving orphaned numbers (0.7183 NDCG@10). QuickSpaces tracks active table schemas across page breaks to bind column and row headers onto every cell (0.8998 NDCG@10), while a binary SHA-256 page Merkle tree re-embeds only mutated pages (97.5% page skip and 96.55% chunk re-embed skip in 0.603 ms).

O(1) TOMBSTONES & DURABLE WORKSTREAMS

Bitset Revocation, RRF Scoring & SQLite WAL Idempotent Tool Flows

Revoking restricted pages flips a single bitmask tombstone_bitmap |= mask in 0.0012 ms (100.0% block rate) without rewriting segments. For multi-step execution, AgentZWorkstreamCompiler compiles JSON specs (allowed_spaces, idempotent_erp_tools, sla_tier, approval_rules) into a 5-stage SQLite WAL workflow with SHA-256 idempotency tokens so retries create 0 duplicate Jira or SAP tickets.

MODULE 01 · PARSERS & PII MASKING quickspaces/multimodal_ingest.py · models.py

Four Format-Specific Parsers & Dynamic Column Redaction

  • Spreadsheet Rollups & PII Detection: Infers numeric columns, pre-computes exact sum, avg, min, and max totals, and flags sensitive columns (SSN, API_KEY, email, phone) on upload.
  • Role-Aware Cell Redaction: Masks flagged cells on read ([REDACTED:SSN], [REDACTED:API_KEY], masked email and phone) for analysts while keeping the source table intact for authorized admins.
  • Call, Dashboard & Doc Parsers: Keeps [MM:SS] speaker timestamps on call transcripts, SQL lineage and KPI deltas on BI dashboards, and §2.1 section anchors on Markdown design docs.
4 File Formats Live File / CSV Upload API
MODULE 02 · ACCESS GATE & HYBRID SEARCH quickspaces/hybrid_retrieval.py · spaces_catalog.py

Pre-Retrieval Permission Gate + BM25 / Cosine RRF + Per-File Pooling

  • Up-Front Permission Check: Checks caller clearance (PUBLIC, INTERNAL, CONFIDENTIAL) and allowed regions (NA, EMEA, APAC) before scoring candidates, blocking 5/5 (100.0%) unauthorized access probes.
  • Keyword + Semantic Rank Fusion: Combines Okapi BM25 exact-term matching with character n-gram cosine similarity via Reciprocal Rank Fusion in 0.70 ms p50 / 2.20 ms p95.
  • Per-File Max-Pooling: Scores each file by its strongest chunk and balances file formats, raising top-3 recall from 80.0% (flat chunks) to 90.0%.

04 · Trade-Offs

Trade-Offs

Comparing flat vector chunking and post-search permission filters against pre-search access predicates, per-file score pooling, and read-time column redaction.

ACCESS CONTROL & RECALL

Pre-Search Access Filtering vs. Post-Search Filtering

Consider a contractor searching for public pricing inside a workspace that also holds 50 confidential board memos. If the search engine fetches the top 5 matches first and drops unauthorized hits second, all 5 slots can be confidential memos, returning zero results even when the public pricing sheet sits at rank 6. Filtering permissions first prevents leaks while preserving recall over authorized files.

PREDICATE EVALUATION

CLEARANCE_RANK Comparison, Regional Set Overlap & Read-Time Masking

can_access_asset(role, asset) checks CLEARANCE_RANK[role.clearance] >= CLEARANCE_RANK[asset.classification] and bool(set(role.regions) & set(asset.regions)) in O(1) per file before building the candidate list. When an INTERNAL analyst views a spreadsheet with flagged PII columns, cells are masked on read instead of maintaining separate sanitized CSV copies.

PRINCIPLE 01 · PRE-SEARCH ISOLATION

Filter Permissions Before Scoring Candidates, Never After

Evaluating clearance tier and regional residency ahead of candidate ranking blocks 100.0% of unauthorized probes (5/5) while ensuring lower-clearance users still get complete answers from public and internal documents.

PRINCIPLE 02 · FORMAT-AWARE RANKING

Keep Native File Structure and Pool Scores at the File Level

Pre-computing spreadsheet column totals, preserving [MM:SS] call timestamps, and pooling chunk scores per file stops long recordings from burying high-signal tables (80.0% → 90.0% top-3 recall in 0.70 ms p50).

PRINCIPLE 03 · AUTOMATED HYGIENE

Pair Self-Serve Uploads with One-Click Security Remediation

Teams upload sensitive spreadsheets and recordings constantly. Scanning columns on ingest and enforcing five workspace controls automatically (59.7 → 100 across 3 workspaces) replaces manual ticket queues with verifiable SHA-256 receipts.
