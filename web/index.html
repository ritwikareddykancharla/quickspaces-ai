How It Works (30-Second Visual Walkthrough)

Why post-retrieval permission filtering leaks sensitive enterprise metrics—and how QuickSpaces enforces zero-leakage multi-modal RAG.

Amazon Quick Suite Inspired Architecture
STEP 01 · PRE-RETRIEVAL ACL

Clearance & Residency Gate

Evaluates caller role (vp_admin, finance_analyst, external_contractor), region (NA, EMEA), and classification tier prior to candidate generation so restricted chunks never enter prompt assembly.

STEP 02 · 4-MODALITY INGEST

Typed Schema & PII Scanner

Parses CSV tables into numeric rollups + PII column detectors (SSN, API_KEY, email, phone), splits .vtt audio into [MM:SS] speaker turns, and indexes BI SQL lineage & RFC anchors.

STEP 03 · BEDROCK NOVA RAG

Cited Q&A + Auto BI Chart

Fuses BM25 + semantic cosine ranks via Reciprocal Rank Fusion (RRF), calls live us.amazon.nova-lite-v1:0 with inline [C1..C5] citations, and synthesizes an SVG BI chart from matched tabular series.

STEP 04 · GOVERNANCE AGENT

5-Rule Remediation (45 → 100)

Audits Spaces for unmasked PII columns, public/guest share drift, missing eu-central-1 KMS CMK pins, unverified BI SLAs, and transcript retention—remediating all 5 with SHA-256 WORM receipts.
